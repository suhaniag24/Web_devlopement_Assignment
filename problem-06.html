My Programming Notes

JavaScript

JavaScript is a programming language mainly used to make web pages interactive and dynamic. It can be used to respond to user actions, change webpage content, create animations, and build interactive web applications.

Example of JavaScript: 


let name = "Suhani";
console.log("Hello " + name);

JavaScript is widely used in web development.

Java

Java is a general-purpose programming language used for developing applications, websites, enterprise software, and Android applications. It is known for being reliable and supporting object-oriented programming.

Example of Java: 


public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Java is known for its portability and reliability.

Python

Python is a simple and powerful programming language used in web development, data science, artificial intelligence, machine learning, automation, and many other fields. Its simple syntax makes it easy for beginners to learn.

Example of Python: 


name = "Suhani"
print("Hello", name)

Python is widely used in Artificial Intelligence and Machine Learning.
